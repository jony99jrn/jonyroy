# Jony Roy — Developer Portfolio

A responsive dark-themed React portfolio built with Vite.

## Run locally

1. Install Node.js (LTS).
2. Extract this project.
3. Open a terminal in the project folder and run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite.

## Customize before publishing

Search the project for these placeholders and update them:

- `YOUR_EMAIL@example.com` — replace with your real email address.
- `https://github.com/` — replace with your GitHub profile.
- `https://linkedin.com/` — replace with your LinkedIn profile.
- Project links and descriptions in `src/main.jsx`.
- Education details in the About section if you want to show your university/program specifics.

The portfolio currently uses example project entries to give you a polished starting point. Keep only projects you have actually built and update their descriptions to match your work.

## Deploy to Vercel

1. Push the project to a GitHub repository.
2. Sign in to Vercel and choose **Add New → Project**.
3. Import the repository.
4. Vercel should detect Vite automatically.
5. Use `npm run build` as the build command and `dist` as the output directory.
6. Click **Deploy**.

No environment variables are required.
